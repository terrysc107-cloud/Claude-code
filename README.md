# Claude Code — Personal Finance Dashboard

A fully functional personal finance pipeline built with Claude Code. Connects your bank via Plaid, stores transactions in Supabase, and renders an AI-powered dashboard hosted on Vercel.

This repo is the course artifact for **Building Real Apps with Claude Code** — a live example of what you can ship when you use Claude Code as your primary development tool.

---

## What It Does

- **Plaid Link** — connect any US bank account in your browser (OAuth-ready for Chase, Schwab, etc.)
- **Supabase** — stores access tokens + all transaction history
- **AI Analysis** — Claude analyzes your last 90 days and generates a financial report on every sync
- **Dashboard** — spending charts, category breakdown, subscription detection, AI chat, CSV export
- **Python sync** — one command pulls the latest transactions and regenerates the dashboard

## Setup

### 1. Clone and install

```bash
git clone https://github.com/terrysc107-cloud/Claude-code
cd Claude-code
pip install -r requirements.txt
```

### 2. Configure environment

```bash
cp .env.example .env
# Edit .env with your credentials
```

Required variables:

```env
PLAID_CLIENT_ID=your_client_id
PLAID_SECRET=your_secret
PLAID_ENV=production          # or sandbox for testing

SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your_anon_key

ANTHROPIC_API_KEY=your_key    # optional — enables AI analysis section
ALLOWED_ORIGIN=https://your-project.vercel.app  # optional — locks API CORS
```

### 3. Set up Supabase tables

Run in your Supabase SQL editor:

```sql
create table plaid_tokens (
  id uuid primary key default gen_random_uuid(),
  item_id text unique not null,
  access_token text not null,
  cursor text default '',
  last_sync timestamptz,
  created_at timestamptz default now()
);

create table transactions (
  id uuid primary key default gen_random_uuid(),
  transaction_id text unique not null,
  account_id text,
  date date,
  authorized_date date,
  name text,
  merchant_name text,
  amount numeric,
  iso_currency_code text,
  pending boolean default false,
  payment_channel text,
  category_primary text,
  category_detailed text,
  sync_time timestamptz,
  created_at timestamptz default now()
);
```

### 4. Deploy Supabase Edge Functions

The Plaid Link UI calls these two Supabase Edge Functions:

- `create-link-token` — creates a Plaid link token
- `exchange-token` — exchanges the public token for an access token

Deploy with the [Supabase CLI](https://supabase.com/docs/guides/local-development):

```bash
supabase functions deploy create-link-token
supabase functions deploy exchange-token
```

Set secrets in your Supabase project dashboard under **Settings → Edge Functions**:
- `PLAID_CLIENT_ID`, `PLAID_SECRET`, `PLAID_ENV`

### 5. Deploy to Vercel

```bash
vercel deploy
```

Or connect the GitHub repo in the Vercel dashboard. The `vercel.json` routes are already configured.

Set the same environment variables in your Vercel project settings.

### 6. Connect your bank

Open your Vercel URL → click **Connect Bank Account** → complete Plaid Link.

### 7. Sync and generate dashboard

```bash
python plaid_sync.py
```

This fetches new transactions, generates an AI analysis, and writes `public/dashboard.html`. Push to GitHub to update the live site:

```bash
git add public/dashboard.html && git commit -m "Update dashboard" && git push
```

## Project Structure

```
public/
  index.html        Plaid Link UI (live on Vercel)
  dashboard.html    Generated dashboard (regenerated by plaid_sync.py)
api/
  create_link_token.py   Vercel serverless — creates Plaid link token
  exchange_token.py      Vercel serverless — exchanges public token
plaid_sync.py       Main sync script — fetch transactions + regenerate dashboard
plaid_analyze.py    Claude API analysis with prompt caching
.claude/
  commands/         Slash commands: /finance, /finance-export, /sparc, /scout, /phase, etc.
  agents/           60+ specialist agents for building and auditing
docs/               Build system docs (TEAM, MASTER-PLAN, PHASE-MODEL, etc.)
phases/             11-phase build playbooks
memory/             DECISIONS, LEARNINGS, PATTERNS, DEBT
```
